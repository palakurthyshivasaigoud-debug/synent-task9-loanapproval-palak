# synent-task9-loanapproval-palak

## Task 9: End-to-End Loan Approval Prediction

This project was built for the Synent Technologies Data Science Internship as an end-to-end data science workflow. It includes data cleaning, EDA, model training, saved model artifacts, and a Streamlit app for user input and prediction output.

## Problem Statement

Banks and lending teams need quick ways to estimate whether a loan application is likely to be approved. In this project, I trained classification models using applicant income, loan amount, credit score, education, employment status, dependents, and asset values to predict loan approval status.

## Dataset

Source: Loan approval prediction dataset from Kaggle.

Files:

| File | Purpose |
| --- | --- |
| `data/loan_approval_dataset.csv` | Raw dataset |
| `data/loan_approval_cleaned.csv` | Cleaned dataset generated by the training script |

Target column:

```text
loan_status
```

## Workflow

1. Loaded the loan approval dataset.
2. Standardized column names and cleaned text values.
3. Removed duplicate rows and dropped `loan_id`.
4. Encoded the loan status target into approved/rejected classes.
5. Created ratio-based features such as loan-to-income and loan-to-asset ratio.
6. Generated EDA charts for approval distribution, CIBIL score, loan amount, education, and correlations.
7. Trained Logistic Regression, Decision Tree, and Random Forest models.
8. Saved the best model package with preprocessing steps.
9. Built a Streamlit app where users enter applicant details and receive a prediction.

## Results

| Model | Accuracy | Precision | Recall | F1 Score |
| --- | ---: | ---: | ---: | ---: |
| Decision Tree | 1.000 | 1.000 | 1.000 | 1.000 |
| Random Forest | 0.999 | 0.998 | 1.000 | 0.999 |
| Logistic Regression | 0.918 | 0.946 | 0.921 | 0.933 |

Best model: Decision Tree.

The very high accuracy should be interpreted carefully. In this dataset, loan status is strongly related to features such as CIBIL score and financial ratios, so the model can separate the classes very easily. This is mentioned so the result is presented honestly instead of being treated as a universal real-world guarantee.

## Streamlit App

The app is available in `app.py`. It collects applicant details, prepares them in the same feature format used during training, and displays the predicted loan status with approval probability.
